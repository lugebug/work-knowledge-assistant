# 项目上下文

这是面向 Windows + Codex 的独立个人工作助手，当前版本为 0.1.0-alpha.1。公开发行源码和安装入口，首次安装创建空库，不携带维护者的账号、聊天、工作事项、自动化任务或其他业务资料。

用户主要通过 Codex 交互，浏览器工作台与命令行使用同一套维护逻辑。Codex 理解原文并判断业务，程序保存来源、版本、人工决定、原完成条件、分析及提醒计划。工作台不内置模型调用，首次接入需要用户本人登录并选择工作资料范围。

读取 `README.md` 和 `docs/first-run.md` 安装；读取 `docs/daily-workflow.md` 整理。当前只开放微信 Windows 4.1.15.55 适配；飞书使用固定版本的官方 CLI。微信目录和聊天正文授权分开，本机没有的历史不能通过安装凭空恢复。

本机身份、时间范围和数据路径保存在被 Git 排除的配置中；数据库保存在代码目录外。个人工作事实及运行结果保存到个人数据目录，不写入公开交接文档。后续改代码、发布或换设备前，更新本目录的决定、待办和工作记录，并核对发布清单。
