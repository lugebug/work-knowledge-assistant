# 重要决定

## 2026-10-19 增量整理与升级

自动整理只处理上轮之后的新资料、修订、人工答复和实际变化，先更新相关工作再汇总项目。已确认属性持续有效，内部复核日期、项目一般进展和重复回执不触发全量重算。真实目标变化、来源授权变化、关键新证据仍按相应对象核对；原目标校验、业务写回、逐版本回执和真实到期提醒保留。

旧安装先核对身份并建立一致备份，再迁移检查记录；不能借迁移清空待整理或覆盖人工决定。定期任务正文通过当前用户的 Codex 工具更新并读回，保持原频率和通知等选择。安装器不接管 Codex 内部文件，不复制维护者的任务、账号或资料。本次只同步增量机制及其原文引用依赖，其他独立运行优化不混入本版。

## 2026-10-18 首版发行范围

采用公开 GitHub 仓库和带安装入口的源码 ZIP，优先 Windows + Codex。安装器处理依赖、独立环境、空库和工作台；Codex 根据随包指引完成本人账号接入、范围选择、首轮整理和定期任务设置。首次登录、企业权限和工作范围由实际用户决定。

代码与个人资料分离；不提供预装业务数据，不复制维护者的登录、提醒接收人或自动化任务。来源按批准身份读取，明确排除和人工修改受保护；无权限、未适配版本和本机缺历史分别保留。

重复安装保留已有资料，未知数据库不接管。发布仅使用明确清单并校验文件摘要；Git 保持文件字节，避免平台换行转换破坏适配校验。SHA-256 用于检出改动，不代替代码签名。

首版不承诺离线 EXE、全版本微信、无人授权首次登录、新电脑免验收或关机后继续本机整理。云端提醒须在各用户自己的飞书中单独配置和实测。整个项目的开源许可尚未选择；第三方许可见 NOTICE.md。
